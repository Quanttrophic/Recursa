# Recursa

A calm, offline study app for the New Jersey real-estate salesperson licensing exam. It works out what you know, what you are starting to forget and what you tend to mix up, then plans a short session for today.

Everything stays on your own computer: no account, no server and no tracking.

## Download
Open **Releases** on the right of this page and download the file for your computer.

| Your computer | Download |
|---|---|
| Windows 10 or 11 | `Recursa-Setup-…-windows-x64.exe` |
| Mac with an Apple chip (M1, M2, M3, M4…) | `Recursa-…-macos-arm64.dmg` |
| Mac with an Intel chip | `Recursa-…-macos-x86_64.dmg` |

Not sure which Mac you have? Choose Apple menu → **About This Mac**. If you see "Chip: Apple", pick arm64. If you see "Processor: Intel", pick x86_64.

## Install

**Windows**
1. Double-click the Setup file. No administrator password is needed.
2. If you see **"Windows protected your PC"**, click **More info**, then **Run anyway**. This appears because the test builds are not yet code-signed.
3. Open Recursa from the Start menu.

**Mac**
1. Double-click the `.dmg`, then drag **Recursa** into **Applications**.
2. The first time, right-click **Recursa** in Applications, choose **Open**, then **Open** again.
3. On macOS 15 or later, if there's no Open button: try to open it once, then go to System Settings → Privacy & Security and click **Open Anyway**.

## Your progress
Your progress is saved automatically in a folder called `.nj_re_trainer` in your home folder. Installing a newer version keeps it.

To move to another computer, use **Settings → Back up**, then restore the backup on the new computer.
